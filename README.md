# snki_pva
This is a repository for a count-base PVA (2.0) of the snail kite project. We are using the time-series to model the stochastic dynamic of the population in six regions in Florida. Specifically, we are aiming to (see code rendered in html with the link):

1) Estimate the impact of reduced growth rate in probability of falling under conservation thresholds ([Q1](https://oaccolombia.github.io/snki_pva/SNKI-PVA-GSS.html))
2) Estimate how changes in environmental variables might affect the growth rate of different subpopulations and how these changes in growth rate affect in turn local and regional persistence probabilities ([Q2](https://oaccolombia.github.io/snki_pva/SNKI-PVA-GSS_water.html))
3) Estimate empirically critical density values that might represent low-density extinction vortices in the population (Q3 - Allee html in preparation)
